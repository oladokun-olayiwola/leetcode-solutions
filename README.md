# LeetCode Solutions

This repository contains my solutions to LeetCode problems. It serves as a collection of my problem-solving practice and a way to track my progress while improving my data structures, algorithms, and Git workflow.

## Repository Workflow

Each LeetCode problem is solved in its own Git branch.

### Branch Naming Convention

```text
leetcode-<problem-number>-<problem-title>
```

Example branches:

```text
leetcode-0001-two-sum
leetcode-0704-binary-search
leetcode-1624-largest-substring-between-two-equal-characters
```

After completing a solution:

1. Create a new branch for the problem.
2. Implement and test the solution.
3. Commit the changes with a descriptive commit message.
4. Push the branch to GitHub.
5. Open a Pull Request and merge it into `main`.

## Commit Message Convention

```text
Add solution for LeetCode <problem-number>
```

Example:

```text
Add solution for LeetCode 1624
```

## Solution Information

Each solution includes:

* Problem number and title
* Source code
* Time complexity
* Space complexity
* Brief explanation of the approach (when applicable)
